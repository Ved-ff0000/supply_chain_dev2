SupplyChain Modern UI — High-end React + Tailwind scaffold

Run locally:

1. Install dependencies

```bash
cd frontend/modern-ui
npm install
```

2. Start dev server

```bash
npm run dev
```

Notes:
- Tailwind is configured for an ultra-dark "antigravity" theme with obsidian surfaces and dynamic accents.
- Fonts: Plus Jakarta Sans (UI) + Fira Code (mono) to match the designer system.
- Animations: Uses `framer-motion` for entrance stagger and interactive motion.
- This scaffold follows the project's design rules: high information density, subtle rules, and restrained accents.
